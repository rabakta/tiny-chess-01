# tiny-chess-01 entry

4 KB chess engine in Python (stdlib only): 0x88 board, alpha-beta with
iterative deepening, transposition table, killer moves, null-move pruning,
late-move reductions, quiescence search, mirrored piece-square tables.
Fixed 20,000 nodes per move, fully deterministic.

Built for the make.fun tiny-chess-01 bounty.
